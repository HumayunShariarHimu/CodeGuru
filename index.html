প্রতিটি বই বা রিসোর্স আলাদা GitHub রিপোজিটরিতে সংরক্ষিত। কার্ডের “শেখা শুরু করুন” লিংকটি সরাসরি সেই মূল রিপোজিটরিতে নিয়ে যায়, যেখানে README ও সূচিপত্র থেকে অধ্যায় পড়া যায়।

কীভাবে অবদান রাখবেন?
